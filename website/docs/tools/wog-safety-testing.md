# WOG Safety Testing Framework

The Whole-of-Government (WOG) safety testing framework defines how Singapore public-sector teams should evaluate AI systems for safety before deployment. It standardises the risk taxonomy, the choice of metrics, and the evaluation protocol used across agencies.

The framework is described in our paper, *Measuring What Matters*, which sets out:

- The set of categories WOG teams should test against, including categories specific to public-sector context (specialised advice, political content, undesirable content).
- The definition of severity levels with concrete examples.
- The recommended approach to dataset construction, including the trade-offs between off-the-shelf benchmarks and locally generated prompts.
- Guidance on metrics — Attack Success Rate, refusal taxonomy, and how to report results.
