# Agentic Risk & Capability Framework

The Agentic Risk and Capability Framework (ARC) is GovTech's reference for assessing and controlling risk in agentic AI systems. It defines:

1. **Baseline risks** that apply to every agentic system, regardless of the specific capabilities it has.
2. A **hierarchical taxonomy of capability-specific risks** — for example, what risks emerge when a system can call tools, persist memory, or take external actions.
3. A **mapping from each risk to evaluations and technical controls**, with an example implementation for each.

Use ARC to scope what to test and what to mitigate once you have decided that a system is agentic.
