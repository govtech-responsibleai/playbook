# Agentic System Checklist

Use this checklist before piloting or launching an agentic system.

## Define

- [ ] Intended use and prohibited use are documented.
- [ ] Agentic capabilities are listed.
- [ ] Tools, data access, memory, and external actions are mapped.
- [ ] Human approval points are defined.

## Evaluate

- [ ] Task success scenarios are tested.
- [ ] Tool-use correctness is tested.
- [ ] Planning reliability is tested.
- [ ] Prompt injection and malicious context scenarios are tested.
- [ ] Data leakage and privilege misuse scenarios are tested.

## Mitigate

- [ ] Tools follow least privilege.
- [ ] Sensitive actions require approval.
- [ ] Tool arguments are validated.
- [ ] Logs and traces are available for review.
- [ ] A safe stop or rollback path exists.
