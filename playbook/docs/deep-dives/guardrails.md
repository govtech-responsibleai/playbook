# Guardrails

!!! info "About this page"

    This page is new in the upcoming Responsible AI Playbook release. It is a short Guardrails primer that points readers at the canonical Mitigations & Controls section and tool pages. All content is new.

Guardrails are protective components that help AI applications behave appropriately and as intended.

Start with [Mitigations & Controls](../mitigations-controls/index.md) for practical guidance. For available GovTech guardrails, see [Sentinel](../tools/sentinel.md) and [LionGuard](../tools/lionguard.md).
